# aawazdoc

An AI phone receptionist for small clinics in India. A patient calls, the AI answers in Hindi, English
or Hinglish, books the appointment into the clinic's Google Sheet and sends a WhatsApp confirmation.
The clinic sees every call, transcript and booking on a dashboard.

Everything lives in [`frontend/`](frontend): the dashboard (`src/`) and the API (`server/`).

- [frontend/README.md](frontend/README.md): what is in the repo and how to run it
- [frontend/docs/GO-LIVE.md](frontend/docs/GO-LIVE.md): keys, deploy and a real phone number
- [render.yaml](render.yaml): one-click deploy of the API and the dashboard on Render
